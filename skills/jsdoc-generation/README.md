# RuixeWolf Agent Skills

Reusable Agent Skills for Codex, OpenCode, Claude Code, Cursor,
GitHub Copilot, and other compatible AI coding agents.

## JSDoc Generation

Enforces concise and consistent JSDoc standards for:

- TypeScript
- JavaScript
- TSX / JSX
- Vue
- MTS / CTS
- MJS / CJS

### Install

```bash
npx skills add RuixeWolf/skills --skill jsdoc-generation
```
